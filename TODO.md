# TODO — Adrobot Campaign Console

## 1. Рабочая интеграция с Keitaro

- [ ] Backend на FastAPI + SQLAlchemy принимает `KEITARO_BASE_URL` и `KEITARO_API_KEY` из переменных окружения.
- [ ] API-ключ не возвращается frontend-у, не выводится в логи и не попадает в Git.
- [ ] Каталоги доменов, групп, источников, офферов и кампаний загружаются из Keitaro; upstream ошибки превращаются в понятные ответы.

## 2. Создание кампании

- [ ] Форма содержит обязательные поля `Name`, `Geo` и `Offer` и рабочую кнопку `Create`.
- [ ] `Geo` принимает один или несколько ISO-кодов стран и валидируется до запроса.
- [ ] Создаваемая кампания получает выбранные домен, группу и источник.
- [ ] Создаются два потока: первый фильтрует указанные страны и редиректит на Google; второй редиректит на выбранный оффер Keitaro.
- [ ] После операции UI показывает результат и реальные ID/числовые показатели ответа.

## 3. Редактор существующей кампании

- [ ] Пользователь может выбрать существующую кампанию и увидеть её текущие офферы и числовые показатели.
- [ ] Редактор добавляет оффер через API Keitaro и обновляет состояние после ответа.
- [ ] Редактор удаляет выбранный оффер через API Keitaro и обновляет состояние после ответа.
- [ ] Кнопки блокируются во время запроса, а ошибки отображаются рядом с операцией.
